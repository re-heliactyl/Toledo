# Language Standards: Code & Agent Rules
 
 All code, variable names, UI labels, user-facing text, error messages, API responses, comments, and agent rules must always be written in English.
 
 ## When this applies
 
 - Writing or modifying any code in `frontend/` or `server-toledo/`.
 - Creating or editing rule files in `AGENTS.md` or `.agents/rules/*.md`.
 - Creating API endpoints, error messages, log messages, or UI components.
 
 ## Rules
 
 - **ALWAYS** write all agent rules (`AGENTS.md` and `.agents/rules/*.md`), specifications, and architectural documentation in English.
 - **NEVER** write, commit, or preserve French or non-English text inside `AGENTS.md` or any rule file in `.agents/rules/`.
 - **ALWAYS** write all code comments, variable names, function names, error messages, and documentation in English.
 - **ALWAYS** write all user-facing text, UI labels, button labels, and toasts in English.
 - **NEVER** hardcode French or non-English strings in frontend components or backend responses.
